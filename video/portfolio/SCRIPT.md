- 길이 44초 · 1280×720 (16:9) · 30fps
- 화면 문구는 포트폴리오 페이지(gooodjobbaby.web.app 사례 연구)에 적힌 내용만 사용
- 내레이션 칸은 화면 아래 자막으로 들어가며, 나중에 음성을 입힐 때 그대로 읽을 수 있는 문장

| 1 | 0–5초 | 인트로 | 따봉이 마스코트가 튀어 오르고 "오늘도 잘했어" 제목, "PRODUCT MANAGER PORTFOLIO" 칩 | 오늘 한 일이 우리 아이의 용돈이 돼요. |

| 3 | 10–17초 | 하루가 돌아가는 방식 | 실제 앱 화면(아이·부모·아이)이 들어오고, 왼쪽에 다섯 단계가 차례로 체크됨: 할 일 체크 → "다 했어요!" 요청 → 부모 승인 → 시트 자동 갱신 → 주 단위 지급 | 설정은 처음 한 번, 그다음은 체크와 승인뿐입니다. |

| 5 | 23–29초 | 데이터 원칙 | 구조도: 아이 앱 → Cloud Functions → 부모의 구글 시트 ← 부모 앱. 시트 상자에 "유일한 원본" 표시 | 아이의 기록은 부모의 구글 시트에만. 서버에는 로그인과 알림에 필요한 설정값만 둡니다. |
